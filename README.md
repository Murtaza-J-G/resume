# Responsive Resume Website

A modern and responsive resume website built with HTML, CSS, and JavaScript. It features a clean user interface, organized sections, and a responsive layout that works smoothly across desktops, tablets, and mobile devices. The project showcases professional information, skills, education, and experience in an attractive and easy-to-navigate format.

## Technologies Used
- **HTML5** – Website structure and content
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactive features and dynamic behavior

## Features
- Responsive UI for all screen sizes
- Clean and modern design
- Well-organized resume sections
- Interactive user interface
- Easy navigation
- Lightweight and fast performance

## Purpose
This project demonstrates my front-end development skills and my ability to build responsive, user-friendly websites using fundamental web technologies.
